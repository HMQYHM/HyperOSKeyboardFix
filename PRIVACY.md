# Privacy Policy

HyperOS Keyboard Fix does not request network access and does not collect,
transmit, sell, or share personal data.

The following information is stored locally on the device:

- the module master switch;
- enabled shortcut switches;
- package names selected by the user for the application allowlist;
- interface language and configuration version.

The module's read-only configuration provider only permits calls from Android's
system UID and the module's own UID. No analytics or advertising SDK is used.

Last updated: July 24, 2026.
